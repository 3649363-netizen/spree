# Терминология русской локализации Spree 6.0.2

Рабочий словарь для операторской панели, кабинета продавца, витрины покупателя и писем. Используем единые термины во всех интерфейсах; уточнения по отдельному контексту отмечены в таблице. Это редакционная основа перевода, её следует обновлять вместе с ресурсами.

## Стиль

- Нейтральный деловой русский, короткие формулировки и глаголы действия.
- Обращение к пользователю на «Вы»; не использовать разговорные сокращения.
- Оставлять названия Spree и технические термины/API-коды без перевода, когда они идентификаторы.
- Не менять переменные `{{...}}`, имена ключей, enum-значения, URL, SKU, номера заказов и коды валют.
- Формулировки в письмах адаптировать как полноценный русский текст, а не дословный перевод интерфейсных строк.

## Формы множественного числа

i18next выбирает русскую форму по `count`; для счётных существительных в русском ресурсе задавать все используемые категории CLDR: `_one`, `_few`, `_many` и `_other`. Не копировать английскую пару `_one`/`_other` без русских форм. Например:

```json
{
  "file_one": "{{count}} файл",
  "file_few": "{{count}} файла",
  "file_many": "{{count}} файлов",
  "file_other": "{{count}} файла"
}
```

`_other` требуется для дробных и прочих значений, которые не попадают в целочисленные категории. Перед переводом сверять, что вызов `t()` передаёт именно параметр `count`; не превращать обычный плейсхолдер `{{count}}` в plural key без соответствующего вызова.

## Даты, числа и валюты

- В панели оператора и кабинете продавца форматтеры дат используют locale `ru` из date-fns; время в русской дате соединяется словом «в». Суммы получают активный `i18n.language` через `useMoneyLocale()`. В витрине дата и сумма передаются форматтерам вместе с locale из сегмента URL; для русского маршрута формат используется как `ru`.
- `useMoneyLocale()` возвращает `i18n.language`; стандартные `Intl`-форматтеры для `ru` дают русские разделители и названия валют. Валюту брать из кода магазина/цены, а не подменять на RUB.
- При ручном форматировании дат использовать `ru`/`ru-RU`, локальный порядок «день месяц год» и 24-часовое время; не собирать даты конкатенацией.
- Суммы и количества форматировать через `Intl.NumberFormat('ru', ...)`: запятая для дробной части, группировка разрядов пробелом по правилам locale. Не вставлять пробелы и символы валюты вручную.

## Условия готовности перевода

Для каждого JSON-ресурса русская версия должна сохранять все английские ключи и интерполяционные переменные. Для каждого plural key проверить `one/few/many/other`; для даты и суммы проверить типовые значения на интерфейсе. Не включать `ru` в список выбора до того, как все три ресурса (dashboard-core, dashboard, seller-dashboard) подготовлены и проверены на отсутствие недостающих ключей.
