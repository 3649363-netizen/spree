## О Spree Commerce

[Spree Commerce](https://spreecommerce.org/) — API-first платформа электронной коммерции с открытым исходным кодом, созданная для быстрорастущих компаний и крупных предприятий.

На Spree можно создавать [B2B-магазины](https://spreecommerce.org/use-cases/headless-b2b-ecommerce/), [несколько магазинов](https://spreecommerce.org/multi-store-ecommerce/), [магазины для разных регионов](https://spreecommerce.org/multi-region-ecommerce/), [маркетплейсы с несколькими продавцами](https://spreecommerce.org/marketplace-ecommerce/) и [мультитенантные торговые платформы](https://spreecommerce.org/multi-tenant-white-label-ecommerce/). Эти модели можно сочетать, чтобы система соответствовала вашему бизнесу.

Если готовое SaaS-решение не даёт нужного контроля и гибкости, Spree может стать подходящей основой.

Spree используют тысячи компаний по всему миру, в том числе GoDaddy, Huckberry, Craftsman, DieHard, Kenmore, Paccar, Maisonette, Goop, Garmentory и Blue Bottle Coffee.
