Spree Commerce — гибкая платформа для создания и управления интернет-магазином. Перед началом продаж нужно выполнить несколько основных шагов.

В этом руководстве описана базовая подготовка магазина: от настройки оплаты и налогов до добавления товаров и подключения витрины. Оно поможет запустить первую версию магазина или разобраться в возможностях Spree.

## Начало работы

После входа в новую установку Spree откроется раздел **Начало работы** со списком задач для подготовки магазина. В зависимости от состояния магазина в списке могут быть настройка способов оплаты и налогов, добавление товаров, адрес поддержки, адрес отправки и подключение витрины. Выполненные задачи исчезают из списка.

### Настройка способов оплаты

Чтобы принимать платежи, настройте хотя бы одного провайдера онлайн-оплаты.

Нажмите **Настроить способы оплаты** или откройте **Настройки → Способы оплаты**.

Над списком доступных способов оплаты отображаются уже включённые, например **Баланс магазина**. В список доступных входят установленные в проекте способы оплаты, например Stripe, Adyen или PayPal.

<Note>В списке отображаются только установленные способы оплаты. Если нужного провайдера нет, попросите разработчика проверить, добавлен ли он в проект.</Note>

Чтобы добавить способ оплаты:

1. Нажмите **Добавить** рядом с нужным провайдером.
2. Заполните поля настройки.
3. Нажмите **Создать**, чтобы включить способ оплаты.

<Note>Для большинства платёжных систем перед настройкой нужна учётная запись у провайдера.</Note>

Подробнее см. в руководстве [«Способы оплаты»](/user/settings/payments).

### Добавление товаров

Добавить товары в каталог можно вручную или импортировать их из CSV. В маркетплейсе можно пригласить продавцов и разрешить им добавлять собственные товары — эта возможность доступна в Spree Enterprise.

Нажмите **Добавить товары**, чтобы перейти к созданию товара. Для большого каталога используйте [импорт товаров из CSV](/user/products/import-and-export), а для маркетплейса — руководство [«Подключение продавцов»](/user/sellers/onboarding).

После добавления товаров установите для них статус **Активен**, чтобы опубликовать их в витрине.

Подробные инструкции см. в руководствах:

- [«Добавление товаров»](/user/products/adding-products)
- [«Варианты товаров»](/user/products/variants)
- [«Управление товарами»](/user/products/products)

### Адрес поддержки покупателей

Укажите адрес электронной почты, по которому покупатели смогут связаться с вами. Он будет показан в витрине и использоваться для обращений в поддержку.

В задаче **Укажите адрес поддержки** нажмите **Настройки писем**, введите адрес и сохраните изменения.

### Настройка налогов

Чтобы правильно начислять налоги при оформлении заказа, настройте налоговые ставки.

В задаче **Настройте налоги** нажмите **Настройки налогов**. Здесь можно задать налоговые ставки вручную или подключить сторонний сервис, например Avalara, а также настроить налоговые категории.

Подробные инструкции см. в руководствах [«Ставки налогов»](/user/settings/tax-rates) и [«Налоговые категории»](/user/settings/tax-categories).

## Доставка

Для физических товаров настройте способы доставки в профиле доставки. Откройте **Настройки → Профили доставки** и выберите профиль магазина по умолчанию либо создайте отдельный профиль для группы товаров. В профиле укажите склады отправки, зоны доставки и доступные способы доставки.

Подробнее о настройке профилей, зон и способов доставки см. в руководстве [«Профили доставки»](/user/settings/delivery-profiles).

<Note>Для цифровых товаров выберите профиль доставки с типом **Цифровая доставка**. Возможности и способы доставки профиля определяют доступные варианты цифровой отгрузки.</Note>
