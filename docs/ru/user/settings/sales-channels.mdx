title: "Каналы продаж"
description: "Настройте каналы продаж для разных витрин, B2B-порталов, касс и приложений с отдельными каталогами и учётом заказов."
---

Каналы продаж позволяют использовать в одной установке Spree несколько отдельных витрин или способов продаж. Для каждого канала можно задать каталог товаров, учёт заказов и маршрутизацию. Канал может представлять интернет-магазин, оптовый портал, мобильное приложение, кассовый терминал или сезонную мини-витрину.

Spree автоматически помечает заказ каналом, через который он поступил. Так можно фильтровать заказы, строить отчёты и настраивать обработку. Товар можно назначить одному или нескольким каналам, чтобы контролировать, какой ассортимент видит каждая аудитория.

Типичные сценарии:

- **Интернет-магазин и касса** — разделяйте онлайн-заказы и покупки в торговой точке для отчётности и обработки.
- **Розница и оптовый портал B2B** — показывайте разный ассортимент и цены разным аудиториям через одну систему.
- **Маркетплейс или партнёрский канал** — указывайте источник заказа для расчёта комиссии.
- **Мобильное приложение** — отдельно учитывайте заказы и конверсию приложения.
- **Сезонная мини-витрина** — предлагайте ограниченный ассортимент, не меняя основную витрину.

<Note>Разработчики связывают витрину или интеграцию с каналом, передавая в запросах API заголовок `X-Spree-Channel` со значением кода канала. Подробнее — в [документации Storefront API](https://spreecommerce.org/docs/api-reference/storefront).</Note>

Откройте **Настройки → Каналы продаж** в группе **Магазин**.

В таблице показаны настроенные каналы:

В меню строки можно выбрать **Изменить** или **Удалить**. Для канала по умолчанию доступно только изменение: магазину необходимо иметь такой канал.

## Создание канала продаж

Нажмите **Новый канал продаж** в правом верхнем углу. Справа откроется панель.

{/* Скриншот 2: форма создания канала продаж. Сделать снимок русской панели. */}

Заполните поля:

- **Название** — внутреннее название канала, например «Приложение iOS» или «Оптовая торговля в ЕС».
- **Код** — постоянный идентификатор, который клиенты API передают в заголовке `X-Spree-Channel`; по нему Spree относит заказ к каналу. Оставьте поле пустым, чтобы сформировать код из названия. Допустимы строчные латинские буквы, цифры, дефис и подчёркивание.
- **Активен** — выключите, чтобы канал перестал принимать заказы, но остался в системе. Неактивный канал также не выбирается по заголовку `X-Spree-Channel`.
- **Канал по умолчанию** — в магазине может быть только один такой канал. Он используется, если другой не выбран, и в него автоматически публикуются новые товары.
- **Стратегия маршрутизации заказов** — определяет, на какие склады направлять заказы этого канала. Подробнее — ниже.
- **Доступ к витрине** — что видят посетители без входа:
  - **Наследовать настройки магазина** — использовать общее значение. Оставьте его, если этот канал не должен отличаться.
  - **Открытый доступ** — любой посетитель может просматривать товары и цены.
  - **Скрывать цены** — для просмотра цен нужно войти в аккаунт; гость должен войти, чтобы оформить заказ.
  - **Требовать вход** — без входа нельзя просматривать каталог.
- **Оформление заказа без аккаунта** — разрешено ли гостям оформлять заказ в этом канале: **Наследовать настройки магазина**, **Разрешено** или **Запрещено**.
- **Каталог по умолчанию** — каталог для покупателей, не входящих в компанию или группу покупателей с собственным каталогом. Оставьте поле пустым, чтобы показывать все товары, опубликованные в канале, или выберите каталог для ограничения ассортимента.
- **Склады** — склады и пункты выдачи, которые обрабатывают заказы канала. Выберите **Все склады** или конкретные склады.

Заполните поля и нажмите **Создать канал продаж**.

<Note>По умолчанию **Доступ к витрине** и **Оформление заказа без аккаунта** наследуют настройки магазина. Задайте для них отдельные значения, только если поведение этого канала должно отличаться. См. [«Сведения о магазине»](/user/settings/store-details).</Note>

### Стратегия маршрутизации заказов

Маршрутизация выбирает склад, который выполнит заказ, если у магазина несколько складов или пунктов выдачи. При поступлении заказа Spree использует стратегию канала, чтобы определить источник каждой отгрузки.

Для каналов разных регионов или типов клиентов можно настроить отдельные правила. Например, направить оптовые заказы на другой склад или обрабатывать все заказы конкретной витрины в одном центре.

Доступны три стратегии:

- **Наследовать настройки магазина** — использовать общую стратегию магазина. Это значение по умолчанию и подходит большинству каналов.
- **Правила (по порядку)** — последовательно применять список заданных вами правил.
- **Устаревшая** — использовать прежний процесс отгрузки Spree.

### Правила маршрутизации заказов

Список правил появляется после создания канала. Создайте канал, затем откройте его повторно, чтобы настроить правила.

Правила применяются сверху вниз. Если правило выбирает склад, Spree использует его; при равном результате проверяется следующее правило. Перетащите правила в нужный порядок:

1. **Приоритетный склад** — сначала выбирает указанный склад независимо от остатков на других складах.
2. **Минимизировать число складов** — старается собрать весь заказ на минимальном числе складов, чтобы уменьшить количество отправлений.
3. **Склад по умолчанию** — используется, если предыдущие правила не выбрали склад.

<Note>Правила действуют, только если для **Стратегии маршрутизации заказов** выбрано значение **Правила (по порядку)**. При других стратегиях список игнорируется.</Note>

## Товары и каналы продаж

При создании товар автоматически назначается только каналу по умолчанию. Остальные каналы нужно назначить вручную. Пока товар не добавлен в канал, он в нём не отображается.

Чтобы изменить доступность товара, откройте его в редакторе и найдите карточку **Публикация**.

{/* Скриншот 4: карточка публикации товара и назначенные каналы. Сделать снимок русской панели. */}

Нажмите **Управлять**, чтобы добавить товар в каналы или убрать его из них.

После назначения канала нажмите его название в карточке **Публикация**, чтобы настроить период действия товара — даты начала и окончания публикации в этом канале.

{/* Скриншот 5: расписание публикации товара в выбранном канале. Сделать снимок русской панели. */}

Доступность товара в каждом канале зависит от статуса публикации:

- **Опубликован** — товар виден покупателям и доступен для покупки в этом канале.
- **Запланирован** — товар станет активным автоматически в заданную дату.
- **Недоступен** — товар назначен каналу, но скрыт от покупателей.

Так можно сформировать отдельный ассортимент для каждой аудитории. Например, оставить на оптовом канале только часть товаров, а на основной витрине показывать весь каталог.

<Note>Если создать товар через Admin API, он не будет назначен ни одному каналу, пока канал явно не указан в запросе.</Note>

### Массовое назначение каналов

Для нескольких товаров достаточно изменить каждый по отдельности. Чтобы назначить канал сразу большому числу товаров, используйте массовые действия в списке товаров.

Откройте **Товары**, отметьте нужные строки — вверху таблицы появится панель массовых действий. Выберите **Добавить в каналы продаж**, чтобы опубликовать товары в канале, или **Удалить из каналов продаж** в меню **Другие действия**, чтобы убрать их.

<Note>Выбор действует только на текущей странице таблицы. Если товары находятся на нескольких страницах, выполните массовое действие отдельно для каждой.</Note>

## Заказы и каналы продаж

Каждый заказ автоматически связывается с каналом, через который он поступил. Это позволяет отслеживать объём продаж и обрабатывать заказы по каналам без ручных меток.

В списке **Заказы** столбец **Канал** показывает источник заказа. Фильтр **Канал** позволяет отобрать заказы конкретного канала.
