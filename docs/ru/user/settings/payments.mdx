Способ оплаты определяет, как покупатель оплачивает заказ и какой провайдер обрабатывает платёж. Большинству магазинов нужно несколько способов: предпочтения покупателей различаются, и один вариант подходит не для каждого заказа.

Например, для розничных покупателей можно подключить оплату картой, а для заказов, созданных сотрудниками, оставить отдельные способы. Компания может оплачивать крупный заказ по счёту, а покупатель в магазине — на кассе. Для каждого случая настройте отдельный способ оплаты; его можно показывать покупателям или оставить только сотрудникам.

Откройте **Настройки → Способы оплаты** в группе **Продажи**.

<Note>Stripe включён в Spree. Чтобы принимать оплату картами, подключите аккаунт Stripe — устанавливать дополнительное расширение не нужно.</Note>

В каждой строке показаны:

- **Название** — название и описание для покупателя.
- **Провайдер** — сервис, который обрабатывает платёж.
- **Витрина** — **Виден**, если способ доступен покупателям, или **Только панель оператора**, если им пользуются сотрудники.
- **Статус** — активен способ оплаты или отключён.

Порядок строк задаёт порядок способов оплаты при оформлении заказа. Перетащите наиболее популярный способ наверх.

### Выбор провайдера

**Провайдер** определяет, кто обрабатывает платёж, и какие поля настройки появятся. Провайдеры бывают двух типов.

**Внешние провайдеры**, например Stripe, подключаются к сторонней платёжной системе. При создании укажите полученные от неё учётные данные.

**Встроенные способы** не требуют учётных данных: платёж не обрабатывается внешним сервисом.

- **Check** — фиксирует, что покупатель оплатит чеком или банковским переводом. Заказ создаётся сразу, а сотрудник отмечает его оплаченным после поступления денег.
- **Store Credit** — позволяет покупателю оплатить заказ средствами, уже зачисленными на его баланс.
- **Custom Payment Source Method** — универсальный способ для расчётов вне Spree, например для корпоративного клиента, которому выставляют счёт.
- **Bogus** — тестовый провайдер, имитирующий платёж без перевода денег. В тестовой установке его название может отображаться как **Credit Card**. Используйте его только для проверки оформления заказа и оставьте видимость **Только панель оператора**, чтобы он не отображался покупателям.

<Note>Названия встроенных типов провайдера могут оставаться на английском. Название и описание самого способа оплаты можно задать отдельно.</Note>

### Данные провайдера

Перед использованием внешнего провайдера добавьте его учётные данные. Поля зависят от провайдера и появляются после его выбора.

Введите ключи из панели самого провайдера. После сохранения значения не отображаются; для замены каждого ключа есть кнопка **Заменить**.

Для встроенных способов оплаты этот раздел не нужен.

### Название и видимость

Настройте отображение способа оплаты:

- **Название** — текст для покупателя при оформлении заказа, например «Банковская карта» или «Оплата по счёту».
- **Описание** — пояснение покупателю, особенно полезное для способов, отличных от оплаты картой.
- **Показывать в витрине** — включено по умолчанию. Если выключить, способ будет доступен только сотрудникам для заказов, созданных в панели.
- **Активен** — включено по умолчанию. Неактивный способ полностью скрывается при оформлении заказа.

<Note>Параметры **Показывать в витрине** и **Активен** выполняют разные задачи. Отключение показа оставляет способ сотрудникам; деактивация скрывает его от всех.</Note>

### Когда списывать оплату

Выберите, когда деньги покупателя будут списаны. По умолчанию каждый способ оплаты наследует настройку магазина, если здесь не указать другое значение.

| Значение | Результат |
|---|---|
| **Использовать настройку магазина** | Применить значение магазина; унаследованное значение отображается в скобках. |
| **При оформлении заказа** | Списать деньги сразу после размещения заказа. |
| **При отправке** | Зарезервировать сумму при оформлении заказа и списать при отправке товаров. |
| **Вручную** | Зарезервировать сумму при оформлении заказа, а списать позднее вручную. |

Выбор зависит от того, когда вы выполняете заказ:

**При оформлении заказа** — самый простой вариант для товаров в наличии, которые быстро отправляются. Оплата уже поступила к началу комплектации, а у каждого заказа сразу есть связанный платёж.

**При отправке** подходит для товаров на заказ, предзаказов и других случаев ожидания. Деньги резервируются при оформлении, чтобы проверить платёжную карту, и списываются, когда посылка отправляется.

**Вручную** подходит для заказов, требующих решения сотрудника: например, корпоративного заказа на одобрении, согласуемой сметы или частичной отправки. Сотрудник списывает деньги, когда заказ готов.

<Warning>Резервирование не действует бессрочно. Срок авторизации карты ограничен правилами платёжной сети. При настройках **При отправке** и **Вручную** выполните заказ или спишите платёж до истечения срока, иначе резервирование придётся оформлять заново.</Warning>

После настройки нажмите **Создать способ оплаты**.

## Изменение способа оплаты

Откройте меню строки и выберите **Изменить**, чтобы обновить название, описание, видимость, статус или учётные данные. В панели изменения провайдер отображается в подзаголовке, а не в списке выбора.

Провайдера существующего способа оплаты изменить нельзя. Чтобы использовать другого, создайте новый способ и отключите прежний.

<Warning>Перед показом покупателям проверьте новый способ оплаты на реальном тестовом заказе. Неверные учётные данные не скрывают способ при оформлении заказа, но платёж не пройдёт.</Warning>

## Удаление способа оплаты

Откройте меню строки и выберите **Удалить**. Spree попросит подтвердить, что способ больше не будет доступен при оформлении заказа.

<Note>Обычно лучше отключить способ, а не удалять его. Деактивация убирает его из оформления новых заказов, но сохраняет связь с заказами, где он уже использовался.</Note>
