Налоговая категория объединяет товары, которые облагаются налогом одинаково. Большинству магазинов нужно как минимум две категории: для товаров по полной ставке и товаров, для которых регион предусматривает другие правила, например книг, детской одежды или продуктов питания.

У категории нет собственной ставки. Это метка, назначаемая товарам; [ставка налога](/user/settings/tax-rates) указывает категорию и процент. Поэтому одна категория может иметь разные ставки в каждой стране продаж.

Откройте **Настройки → Налоги** в группе **Продажи** и выберите вкладку **Категории**. Обзор см. в разделе [«Налоги»](/user/settings/taxes).

В строке показаны:

- **Название** — название категории и её описание.
- **Налоговый код** — код, по которому категорию распознаёт внешний налоговый сервис, если он используется.
- **По умолчанию** — категория для товаров, которым не назначена своя.

## Создание налоговой категории

Нажмите **Добавить налоговую категорию**.

{/* Скриншот 2: форма добавления налоговой категории. Сделать снимок русской панели. */}

- **Название** — укажите тип налогообложения, а не вид товара, например «Сниженная ставка» или «Нулевая ставка». Одна категория обычно подходит для нескольких видов товаров.
- **Налоговый код** — укажите только если внешний провайдер, например Avalara, требует собственный код. В остальных случаях оставьте поле пустым.
- **Описание** — необязательная внутренняя заметка о том, какие товары относятся к категории. Полезно добавить её, потому что понятие «Сниженная ставка» в разных странах различается.
- **По умолчанию** — категория, на которую будут переходить товары без собственной категории.

Нажмите **Создать налоговую категорию**.

<Warning>Назначение категории по умолчанию снимает этот статус с предыдущей категории. Категория по умолчанию может быть только одна; перед переключением Spree не предупреждает, какая категория потеряет этот статус.</Warning>

<Note>Сама категория не начисляет налог. Пока ставка не ссылается на неё, товары этой категории не облагаются налогом. Создайте категорию, затем добавьте для неё ставку на странице [«Ставки налогов»](/user/settings/tax-rates).</Note>

## Назначение налоговой категории

Категорию можно назначить товару или варианту товара в редакторе. При расчёте налога для позиции заказа Spree использует первое найденное значение:

1. **Налоговая категория варианта**, если она указана.
2. **Налоговая категория товара**, если у варианта её нет.
3. **Категория магазина по умолчанию**, если категория не задана ни товару, ни варианту.

Категория товара служит значением для всех его вариантов. Укажите отдельную категорию только для вариантов, которым нужно отличающееся налогообложение.

<Note>Если варианты одного товара облагаются по-разному, разделять их на отдельные товары не нужно. Назначьте товару категорию для большинства вариантов, а для остальных задайте её отдельно.</Note>

## Изменение налоговой категории

Откройте меню строки и выберите **Изменить**. Переименование безопасно: товары и ставки связаны с категорией, а не с её названием.

## Удаление налоговой категории

Откройте меню строки и выберите **Удалить**.

<Warning>После удаления товары перейдут на резервную категорию. Вариант использует категорию товара, а товар без неё — категорию магазина по умолчанию. До удаления проверьте, что для резервной категории есть ставка во всех регионах продаж. Иначе товары не будут облагаться налогом.</Warning>
