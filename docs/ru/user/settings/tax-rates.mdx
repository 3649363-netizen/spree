Ставка налога задаёт процент, который нужно собирать, и место, где он применяется. Каждая ставка связывает [налоговую категорию](/user/settings/tax-categories) с местом продажи: товары этой категории при доставке туда облагаются указанным процентом.

Значения ставок устанавливает налоговый орган в каждой стране или регионе продаж. В Spree нужно задать эти значения, чтобы система применяла их к заказам.

Обычно требуется несколько ставок: по одной на категорию и страну, а в странах с налогообложением по штатам — дополнительные ставки. Например, для стандартных и льготных товаров в трёх странах нужно шесть ставок.

Откройте **Настройки → Налоги** в группе **Продажи** и выберите вкладку **Ставки**. Общий обзор см. в разделе [«Налоги»](/user/settings/taxes).

<Note>Ставки настраивают встроенный механизм расчёта налогов Spree, но не выбирают механизм для рынка. Если используется внешний налоговый сервис, выберите его в поле **Механизм расчёта налогов** на каждом [рынке](/user/settings/markets). Вкладка **Ставки** показывает рынки, где подключённый сервис заменяет эти ставки.</Note>

В строке показаны:

- **Название** — название ставки.
- **Ставка** — начисляемый процент.
- **Применяется к** — страна и, если указано, штат.

## Создание ставки налога

Нажмите **Добавить ставку налога**.

{/* Скриншот 2: панель добавления ставки. Сделать снимок русской панели. */}

- **Название** — текст в строке налога для покупателя. Используйте понятное ему название, например НДС или налог с продаж.
- **Ставка** — процент, введённый целым числом. Для 20% укажите `20`.
- **Налоговая категория** — товары, к которым применяется ставка. Она действует только для товаров с этой категорией.
- **Страна** — место применения ставки. Если оставить поле пустым, ставка будет действовать во всех странах.
- **Штат** — ограничивает действие одним штатом. Поле появляется после выбора страны, в которой есть штаты.
- **Показывать ставку в подписи налога** — добавляет процент в строку для покупателя, например «НДС (20%)» вместо «НДС».

Нажмите **Создать ставку налога**.

<Warning>Если не указать страну, ставка применяется во всех странах. Иногда это необходимо, но часто становится причиной начисления налога покупателям, которые не должны его платить.</Warning>

<Note>Параметр **Цены включают налог** задаётся для каждого [рынка](/user/settings/markets), а не для ставки.</Note>

## Изменение ставки налога

Откройте меню строки и выберите **Изменить**.

Изменения влияют только на новые расчёты. Уже размещённые заказы сохраняют начисленный налог; обновление ставки не меняет историю заказов.

## Удаление ставки налога

Откройте меню строки и выберите **Удалить**.

<Warning>После удаления налог перестанет начисляться для категории в соответствующем регионе. Перед удалением убедитесь, что эти товары покрывает другая ставка.</Warning>
