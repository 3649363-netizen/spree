Параметры расчёта налогов заказа находятся на одном экране. Откройте **Настройки → Налоги** в группе **Продажи**.

На странице есть три вкладки:

- **Категории** — группировка товаров по налогообложению, например по стандартной или сниженной ставке. См. [«Налоговые категории»](/user/settings/tax-categories).
- **Ставки** — проценты, которые встроенный механизм Spree начисляет для категории и местоположения. См. [«Ставки налогов»](/user/settings/tax-rates).
- **Причины освобождения от налога** — основания, по которым компания может покупать без налога. Подробнее — ниже.

Доступные вкладки зависят от вашей роли и разрешений.

## Какой сервис рассчитывает налог

Для каждого [рынка](/user/settings/markets) выберите, кто рассчитывает налог: встроенный механизм Spree или подключённый сервис, например Avalara. В блоке **Расчёт налогов** под заголовком перечислены рынки и используемые сервисы, например **Avalara AvaTax в США**. Нажмите **Управлять рынками**, чтобы изменить настройки.

Это важно для вкладки **Ставки**. Налоговые ставки Spree применяются только к рынкам, использующим встроенный механизм. Подключённый сервис рассчитывает налог самостоятельно и не использует эти ставки. Вкладка **Ставки** показывает рынки, для которых задан внешний сервис, чтобы вы знали, где ваши ставки не применяются.

## Причины освобождения от налога

Причина описывает, почему компания покупает товар без налога, например для перепродажи или государственных нужд. Сотрудник выбирает её при добавлении [сертификата освобождения от налога](/user/customers/companies) компании.

У каждой причины есть **Название** — текст для вашей команды — и **Код**, который передаётся налоговому сервису. Встроенный расчёт Spree хранит код только как справочную информацию, поэтому подойдёт короткое обозначение. Если рынок использует Avalara, код определяет освобождение: форма предложит коды Avalara, например `G` для перепродажи или `A` для федерального правительства. Название можно задать любое, но для каждой причины выберите код Avalara.

В новом магазине есть шесть причин:

- Сельское хозяйство
- Благотворительная организация
- Образовательное учреждение
- Государственная организация
- Производство
- Перепродажа

Чтобы добавить причину, нажмите **Добавить причину** и заполните поля:

- **Название** — текст, который сотрудник выберет в сертификате.
- **Код** — значение для налогового сервиса; сохраняется заглавными буквами.
- **Доступно для новых записей** — включено по умолчанию. Отключите, чтобы причина больше не предлагалась в новых сертификатах.

<Note>Название и код причины можно изменить в любое время; изменения отразятся на связанных сертификатах. Уже размещённые заказы сохраняют применённую при расчёте причину. Причину, используемую в сертификатах, удалить нельзя, но можно отключить для новых записей.</Note>
