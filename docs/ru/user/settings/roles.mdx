Роль — это набор разрешений для сотрудника. Она определяет, какие разделы панели управления он может открывать и изменять.

Большинству магазинов достаточно трёх-четырёх ролей. Сотрудникам склада нужны остатки и отгрузки, но не выплаты или API-ключи. Специалисту поддержки нужны заказы и покупатели, но ему не требуется менять цены. Сначала предоставить всем полный доступ проще, но позже сложнее понять, кто и что изменил.

Откройте **Настройки → Роли** в группе **Пользователи и разрешения**.

В строке роли показаны:

- **Роль** — название.
- **Разрешения** — метка **Полный доступ**, **Нет разрешений** или число предоставленных прав.
- **Участники** — число сотрудников с этой ролью.

Роль, защищённая Spree от изменений, помечена как **Защищена**.

## Создание роли

Нажмите **Добавить роль**.

{/* Скриншот 2: шаблоны и таблица разрешений новой роли. Сделать снимок русской панели. */}

1. При необходимости выберите один из трёх шаблонов в разделе **Начать с**: **Менеджер заказов**, **Специалист по каталогу** или **Поддержка**. Шаблон заполнит таблицу подходящим набором разрешений.
2. Укажите **Название** роли и при необходимости **Описание**.
3. Настройте разрешения в таблице.
4. Нажмите **Сохранить**.

После этого роль станет доступна при [приглашении или изменении сотрудника](/user/settings/staff).

### Настройка разрешений

В таблице есть строка для каждого ресурса и два флажка: **Просмотр** разрешает открыть раздел, **Управление** — изменять его.

Три кнопки над таблицей применяют настройку ко всем строкам: **Только чтение**, **Полный доступ** и **Очистить**. Часто быстрее выбрать один из вариантов и затем скорректировать отдельные строки, чем настраивать всё вручную.

### Доступные разрешения

Таблица содержит 28 ресурсов в 9 группах.

| Группа | Ресурс | Что включает |
|---|---|---|
| **Аналитика** | Панель | Аналитика продаж и эффективности |
| | Отчёты | Сохранённые и встроенные отчёты |
| **Заказы** | Заказы | Заказы, позиции, возвраты, обмены и обращения |
| | Платежи | Оплаты заказов и списание средств |
| | Отгрузки | Комплектация, отправка и отслеживание заказов |
| | Возврат средств | Оформление и просмотр возвратов средств |
| **Каталог** | Товары | Товары, варианты, опции, цены и медиафайлы |
| | Типы товаров | Шаблоны типов товаров и их дополнительные поля |
| | Публикация | Видимость товаров в витрине и расписание публикации |
| | Медиафайлы | Изображения, видео и файлы медиатеки |
| | Категории | Дерево категорий и таксономии |
| | Подборки | Подборки товаров, созданные вручную или по правилам |
| | Остатки | Остатки, склады, перемещения и передача запасов |
| | Закупки | Поставщики и заказы на закупку |
| **Покупатели** | Покупатели | Аккаунты, адреса, карты и группы покупателей |
| **Продавцы** | Продавцы | Аккаунты продавцов, подключение и одобрение |
| | Комиссии | Ставки комиссии и удержания с продаж продавцов |
| | Выплаты | Выплаты продавцам и их график |
| **Лояльность** | Подарочные карты | Подарочные карты и их наборы |
| | Баланс магазина | Балансы средств покупателей в магазине |
| **Маркетинг** | Акции | Акции, правила и коды купонов |
| **Настройки** | Настройки | Параметры магазина, оплаты, доставки, налогов и каналов продаж |
| | Способы доставки | Варианты, тарифы и условия доставки |
| | Типы упаковки | Коробки, короба и паллеты |
| | Вебхуки | Адреса вебхуков и доставка событий |
| | Интеграции | Данные доступа и соединения с провайдерами |
| **Доступ** | API-ключи | Создание и отзыв ключей API |
| | Сотрудники и роли | Команда, приглашения, роли и разрешения |

<Note>Для ресурса **Панель** можно включить просмотр, но не управление, поэтому доступен только один из двух флажков.</Note>

<Warning>Ресурс **Сотрудники и роли** позволяет менять разрешения, в том числе собственные. Предоставляйте право **Управление** только тем, кому готовы доверить полный доступ: пользователь с этим правом может назначить его себе.</Warning>

## Изменение роли

Откройте меню строки, выберите **Изменить**, настройте разрешения и сохраните изменения.

Изменения применяются ко всем сотрудникам с этой ролью. Если сократить доступ, он будет сокращён сразу для каждого участника.

<Note>Встроенная роль **Администратор** защищена от изменений. Чтобы настроить собственный вариант, создайте новую роль и выберите **Полный доступ** как основу.</Note>
