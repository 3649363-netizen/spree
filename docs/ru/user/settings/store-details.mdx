Настройки магазина задают значения по умолчанию для всего магазина. Они определяют, как магазин отображается покупателям, как нумеруются заказы, когда списываются деньги, учитываются ли остатки и что посетители видят до входа в аккаунт.

Большинство параметров задают один раз при настройке. Некоторые полезно знать заранее, потому что они меняют обработку всех новых заказов.

Откройте **Настройки → Магазин** в группе **Магазин**.

<Note>Настройки расположены на одной длинной странице с разделами и единственной кнопкой **Сохранить** вверху. Кнопка становится активной после изменения параметра и сохраняет всю страницу целиком.</Note>

## Основные сведения

Название, под которым работает ваша компания. Это единственное значение на странице, которое покупатели видят повсюду, поэтому задайте его до открытия магазина.

- **Название магазина** — отображаемое название. Оно показывается в панели управления, письмах и витрине.

## Стандарты и форматы

Параметры языка и единиц измерения. Они влияют на то, что видит команда в панели, и на единицы измерения товаров. Выбирайте их с учётом внутренних процессов, а не расположения покупателей.

- **Язык панели управления** — язык интерфейса для сотрудников. Он не меняет язык витрины.
- **Часовой пояс** — по нему отображаются даты и время в панели управления.
- **Система единиц** — **Метрическая** или **Имперская**; используется для размеров товаров.
- **Единица измерения массы** — **килограмм (кг)** или **грамм (г)** для метрической системы, **фунт (lb)** или **унция (oz)** для имперской.

## Доступ к витрине

Определяет, что посетители видят до входа в аккаунт и могут ли они оформить заказ без регистрации. Это позволяет выбрать между открытым розничным магазином и магазином для оптовых покупателей, где цены доступны только одобренным клиентам.

{/* Скриншот 2: параметры доступа к витрине и оформления заказа гостем. Сделать снимок русской панели. */}

- **Доступ к витрине** — настройка по умолчанию для посетителей без входа:
  - **Открытый доступ** — любой посетитель может смотреть каталог и цены.
  - **Скрывать цены** — для просмотра цен нужно войти в аккаунт. Для оформления заказа гость также должен войти.
  - **Требовать вход** — посетитель должен войти, чтобы просматривать каталог.
- **Оформление заказа без аккаунта** — разрешено ли покупателю оформить заказ без создания аккаунта.

<Note>Канал продаж может переопределить оба значения. Если после изменения параметра витрина работает не так, как ожидалось, проверьте настройки самого канала продаж.</Note>

Два ограниченных режима работают по-разному:

- **Скрывать цены** обычно выбирают оптовые магазины. Посетитель может смотреть ассортимент, но увидит цены только после одобрения аккаунта.
- **Требовать вход** скрывает и цены, и каталог. Этот режим подходит, если сам ассортимент должен быть закрытым.

## Адреса

Настройте, какие данные покупатель должен указать при вводе адреса. Каждое дополнительное поле усложняет оформление заказа, поэтому запрашивайте только действительно необходимые сведения.

- **Поле «Компания»** — показывать поле для названия компании в адресной форме при оформлении заказа. Включите его, если продаёте организациям.
- **Требовать номер телефона** — сделать телефон обязательным в адресах покупателей. Он может требоваться службам доставки.

## Номера заказов

Задайте формат номеров заказов и других документов. По этим номерам сотрудники ищут заказы, а покупатели ссылаются на них в переписке.

{/* Скриншот 3: настройки формата нумерации и пример номера. Сделать снимок русской панели. */}

- **Формат нумерации**:
  - **Последовательный** — номера увеличиваются от начального значения. Их проще продиктовать по телефону и отсортировать.
  - **Случайный** — номер нельзя предсказать, поэтому по нему не определить количество заказов магазина.
- **Префикс** и **Суффикс** — текст перед номером или после него, например `R` в начале.
- **Начать нумерацию с** — начальное значение счётчика.
- **Предварительный просмотр** — показывает пример следующего номера при изменении параметров.

<Warning>Параметр **Начать нумерацию с** можно изменить только до появления первого заказа. После создания заказа поле блокируется: уже выданные номера не меняются. Настройте начальное значение заранее.</Warning>

Эти параметры применяются только к новым заказам.

## Оплата

Выберите момент списания денег и адрес, по которому рассчитывается налог. Параметр списания действует для всех способов оплаты, кроме тех, для которых задано отдельное значение.

{/* Скриншот 4: момент списания и адрес для расчёта налога. Сделать снимок русской панели. */}

- **Когда списывать оплату** — значение по умолчанию для способов оплаты:
  - **При оформлении заказа** — списать деньги сразу после размещения заказа.
  - **При отправке** — зарезервировать сумму при оформлении заказа и списать её при отправке товаров.
  - **Вручную** — зарезервировать сумму при оформлении заказа, а списание выполнить позже вручную.
- **Рассчитывать налог по адресу доставки** — рассчитывать налог по адресу доставки покупателя. Отключите параметр, чтобы использовать платёжный адрес.

<Note>Отдельный способ оплаты может переопределить значение **Когда списывать оплату**. Подробнее — в разделе [«Способы оплаты»](/user/settings/payments).</Note>

## Запасы

Настройте учёт и резервирование остатков. Параметры определяют, ведёт ли Spree учёт количества, резервируется ли товар на время оформления заказа и когда команда получает предупреждение о малом остатке.

{/* Скриншот 5: учёт запасов и порог малого остатка. Сделать снимок русской панели. */}

- **Отслеживать остатки** — учитывать доступное количество. Отключите параметр, если все товары всегда доступны, например для услуг или товаров на заказ.
- **Резервировать остатки при оформлении заказа** — временно зарезервировать товар, чтобы один экземпляр не продали двум покупателям.
- **Порог малого остатка** — отслеживаемый вариант считается заканчивающимся, если его количество не превышает это значение. Установите `0`, чтобы отключить предупреждение.

<Warning>Отключение параметра **Отслеживать остатки** прекращает учёт для всех товаров магазина. Если постоянно доступна только часть товаров, оставьте учёт включённым и разрешите для этих товаров продажи под заказ.</Warning>

## Источник цен

Выберите систему, из которой берутся цены. Большинство магазинов используют собственный каталог и прайс-листы. Если цены определяет ERP-система или система договорных цен, их может предоставлять эта система.

- **Источник цен** — **Spree (встроенный)** использует каталог и прайс-листы магазина. Вместо него можно подключить внешний источник.

Этот параметр нужен магазинам, где ERP или система договорных цен является основным источником стоимости. Настройка выполняется разработчиком; ссылка в этом разделе ведёт к документации по созданию провайдера.

## Источник остатков

Выберите систему, из которой берутся остатки. Этот параметр нужен, если главным источником является складская или ERP-система, а не Spree.

- **Источник данных об остатках** — **Spree (встроенный)** использует записи о запасах магазина. Вместо него можно подключить внешнюю систему.

Внешний источник проверяется при добавлении товара в корзину и при оформлении заказа. В списках товаров по-прежнему показываются остатки Spree.

## Каталог

Настройте три параметра поведения товаров в магазине. Особенно внимательно прочитайте описание истории цен: она может быть важна для соблюдения правил индикации скидок.

{/* Скриншот 6: три параметра каталога. Сделать снимок русской панели. */}

- **Показывать товары без цены** — отображать товары, для которых нет цены в валюте покупателя. Если параметр выключен, такие товары скрыты.
- **Сохранять историю цен** — хранить прежние цены, чтобы витрина могла показывать минимальную цену за последние 30 дней.
- **Разрешить одинаковые артикулы** — разрешить нескольким вариантам использовать один артикул SKU.

<Note>История цен нужна, в частности, для правил ЕС, согласно которым скидка указывается относительно минимальной цены за предыдущие 30 дней. Включите настройку до начала скидок: история накапливается только с момента включения.</Note>

## Цифровые загрузки

Задайте срок действия ссылки на скачивание и число доступных загрузок по умолчанию. Параметры распространяются на все цифровые товары; при необходимости отдельный файл может иметь собственные ограничения.

{/* Скриншот 7: ограничения срока действия и числа загрузок. Сделать снимок русской панели. */}

- **Ограничить число загрузок** — если параметр выключен, покупатель может скачивать файл сколько угодно раз.
- **Разрешённое число загрузок** — сколько раз покупатель может скачать файл.
- **Ограничить срок загрузки** — если параметр выключен, ссылки не истекают.
- **Доступно дней** — сколько дней действует ссылка.

## Сохранение изменений

Нажмите **Сохранить** вверху страницы. Кнопка активируется после изменения параметров и сохраняет все разделы целиком. Можно настроить страницу и сохранить изменения один раз.
