title: "Профили доставки"

Профиль доставки — это набор правил отправки группы товаров. В нём задаются склады отправки, направления доставки и способы, доступные для каждого направления. У каждого товара есть профиль; от него, адреса покупателя и состава корзины зависит, какие способы доставки появятся при оформлении заказа.

Многим магазинам нужно несколько профилей. Крупную мебель доставляют не так, как обувь, а цифровые товары не нужно отправлять физически. Вместо настройки правил для каждого товара создайте профили для разных групп и назначьте их товарам.

Откройте **Настройки → Профили доставки** в группе **Доставка и отгрузка**.

## Список профилей доставки

В каждой строке показаны:

- **Название** — название профиля. Один профиль помечен как **По умолчанию**.
- **Возможности** — какие варианты доступны: **Доставка**, **Самовывоз**, **Цифровая доставка** или их сочетание.
- **Склады отправки** — число складов, с которых отправляются товары, или отметка **Все склады**.
- **Товары** — количество товаров, назначенных профилю.
- **Зоны** — количество зон назначения.
- **Способы** — общее количество способов доставки профиля.

<Note>Количество **Товары** доступно только для просмотра. Чтобы назначить товар профилю, откройте страницу товара.</Note>

## Создание профиля доставки

Нажмите **Добавить профиль**.

{/* Скриншот 2: форма нового профиля, тип и склады отправки. Сделать снимок русской панели. */}

- **Название** — назовите профиль по типу товаров, например «Крупногабаритные товары» или «Цифровые товары», а не по перевозчику.
- **Тип** — **Физическая доставка** для товаров, которые нужно отправлять, или **Цифровая доставка** для загружаемых файлов. Тип определяет, какие провайдеры отгрузки доступны способам этого профиля.
- **Склады отправки** — выберите **Все склады** или **Выбранные склады** и укажите места хранения, откуда отправляются товары.

Нажмите **Создать профиль**, затем откройте его и добавьте зоны и способы доставки.

<Warning>Тип профиля нельзя изменить после создания. Если выбрать неверный тип, создайте новый профиль и переназначьте товары.</Warning>

## Структура профиля

Профиль доставки состоит из трёх уровней: **склад отправки**, доступные ему **зоны** и способы **доставки** в каждой зоне.

{/* Скриншот 3: склады, зоны и способы в профиле. Сделать снимок русской панели. */}

В правой части страницы находятся две панели настроек:

- **Основные сведения** — **Название**, **Тип** (его нельзя изменить после создания) и параметр **По умолчанию**. Этот профиль применяется к товарам, которым не назначен отдельный.
- **Склады отправки** — **Все склады** или выбор отдельных складов.

### Отправка с нескольких складов

Если товары отправляются с нескольких складов, а тарифы различаются, нажмите **Разделить склады отправки**. Профиль разобьётся на группы складов с отдельными зонами и способами. Например, для товара, отправляемого из Амстердама и Калифорнии, можно задать разные цены.

Если тариф одинаковый с любого склада, оставьте один общий вариант.

## Добавление зоны доставки

Зона — набор адресов, по которым может предлагаться способ доставки. В нужной группе складов нажмите **Добавить зону доставки**.

{/* Скриншот 4: редактор зоны и включённые страны. Сделать снимок русской панели. */}

Назовите зону по региону и выберите страны. В одну зону можно включить одну страну или множество. Например, общую зону **Международная** часто проще поддерживать, чем отдельную для каждой страны.

<Note>В каждом профиле есть контейнер **Без ограничения по зоне**. Размещённые в нём способы предлагаются везде, куда распространяется профиль, независимо от адреса.</Note>

<Warning>Если адрес покупателя не входит ни в одну зону профиля, при оформлении заказа ему не будет доступен способ доставки. Проверьте, что профили охватывают все места, куда вы планируете продавать.</Warning>

### Правила для почтовых индексов

Для точной настройки задайте правила почтовых индексов внутри страны. Так можно выделить территории с более дорогой доставкой или исключить удалённые индексы из ускоренной доставки.

Для каждого правила доступны три поля:

- **Префикс** — совпадает с любым индексом, который начинается с указанного текста. Например, `IV` охватывает соответствующие индексы Шотландского нагорья. Работает с любым форматом.
- **От** и **До** — задают диапазон включительно. Диапазон `1000`–`1999` включает оба значения и все числа между ними.

<Warning>**Префикс** и диапазон **От / До** — альтернативные варианты. Для одного правила укажите либо префикс, либо диапазон. Если заполнить оба, правило не сохранится.</Warning>

Выбор зависит от формата индексов в стране. **От** и **До** подходят только для числовых индексов, например в Нидерландах или США. В странах, где используются буквы, настройте **Префикс**.

## Добавление способа доставки

Способ доставки — это вариант, который покупатель выбирает при оформлении заказа. Нажмите **Добавить способ** внутри нужной зоны.

{/* Скриншот 5: провайдеры, калькулятор и условия способа доставки. Сделать снимок русской панели. */}

В боковой панели настройте несколько разделов.

### Провайдеры

Выберите, кто выполняет доставку и откуда берётся цена. Большинство магазинов может оставить значения по умолчанию и задать цену самостоятельно.

- **Провайдер отгрузки** — как передаются и отслеживаются отправления:
  - **Вручную** — для товаров, которые вы отправляете самостоятельно.
  - **Самовывоз** — для выдачи покупателю.
  - **Пункт выдачи** — для стороннего пункта выдачи.
- **Провайдер тарифа доставки** — источник цены:
  - **Внутренний** — рассчитывает цену по калькулятору ниже; обычно это подходящий вариант.
  - **Грузовая доставка** — для грузоперевозчиков.

<Note>В обоих списках может отображаться неактивный пункт «Подключите EasyPost, чтобы использовать». Это подсказка, а не доступный вариант. После подключения EasyPost способы смогут получать актуальные тарифы перевозчика вместо расчёта по внутреннему калькулятору.</Note>

### Название и видимость

Задайте название для покупателей, аудиторию и места использования. Покупатель увидит только **Название**, поэтому укажите скорость или тип доставки, а не только имя перевозчика.

- **Название** — текст при оформлении заказа, например «На следующий день», а не «DHL».
- **Внутреннее название** — подпись, которую видит команда; полезна, если варианты для покупателей похожи.
- **Код** — короткий идентификатор для интеграций и экспорта.
- **Показывать в витрине** — включено по умолчанию. Отключите, чтобы оставить способ только для заказов, созданных сотрудниками.
- **Доступно продавцам** — выключено по умолчанию. Включите, чтобы продавцы marketplace могли использовать этот способ.

### Цена

Задайте стоимость и правила налогообложения доставки.

- **Калькулятор тарифа** — способ расчёта цены. Доступные калькуляторы описаны ниже.
- **Налоговая категория** — налог, который применяется к стоимости доставки, если доставка облагается налогом в регионе продаж.
- **Валюта** — валюта тарифа. Она применяется только к калькуляторам с фиксированной стоимостью.

#### Калькуляторы тарифа

Калькулятор определяет, сколько стоит доставка. Доступно шесть вариантов:

| Калькулятор | Расчёт |
|---|---|
| **Фиксированная ставка** | Одна цена за заказ независимо от состава корзины. Простой вариант по умолчанию для большинства способов. |
| **За единицу товара** | Цена за каждый товар в корзине. Для пяти товаров стоимость будет в пять раз выше, чем для одного. |
| **Процент от суммы** | Процент от суммы заказа; стоимость доставки увеличивается вместе с корзиной. |
| **Гибкий тариф** | Цена за первый товар и меньшая доплата за каждый следующий, до заданного предела. Подходит товарам, которые отправляются одной посылкой. |
| **Тариф по сумме заказа** | Одна ставка до заданной суммы заказа и сниженная ставка выше неё. |
| **Цифровая доставка** | Для загрузок, которые не требуют физической отправки. |

### Сроки и отслеживание

Укажите покупателю ожидаемый срок и ссылку для отслеживания. Эти значения не меняют цену, но помогают снизить число вопросов о статусе заказа.

- **Ожидаемый срок доставки, рабочие дни** — минимальное и максимальное число рабочих дней, отображаемое при оформлении заказа.
- **Ссылка для отслеживания** — ссылка перевозчика; подставьте `:tracking` на место номера отправления.

### Условия

Условия определяют, когда способ доставки предлагается — в зависимости от корзины или покупателя. Без условий способ доступен всем, кто подходит к этой зоне. Нажмите **Добавить условие** и выберите:

- **Сумма товаров** — предлагать способ только при сумме выше или ниже заданной. Так настраивается бесплатная доставка от порога.
- **Вес** — предлагать способ в пределах диапазона веса.
- **Исключённые товары** — скрывать способ, если в корзине есть выбранные товары.
- **Канал** — ограничить способ определёнными каналами продаж.
- **Объём** — ограничить способ диапазоном объёма.
- **Компания** — предлагать способ только выбранным бизнес-клиентам.

Если условия не заданы, способ предлагается во всех подходящих заказах.

<Note>Чтобы настроить бесплатную доставку от определённой суммы, добавьте условие **Сумма товаров** к способу с нулевой ценой. Отдельного параметра для этого нет.</Note>

Закончив, нажмите **Создать способ доставки**.

## Самовывоз

Самовывоз используется, когда покупатель лично забирает заказ. В профиле для него предусмотрен отдельный раздел вне групп складов: при самовывозе нет адреса назначения и не применяются зоны.

{/* Скриншот 6: раздел самовывоза, способ и склады выдачи. Сделать снимок русской панели. */}

Добавьте способ так же, как остальные, выбрав **Самовывоз** как провайдера отгрузки. Затем отметьте склады в разделе **Забрать со склада**. Покупатель сможет выбрать только отмеченные места.

<Warning>Флажки **Забрать со склада** сохраняются сразу после нажатия. На панели нет кнопки **Сохранить** или подтверждения, поэтому ошибочная отметка применяется немедленно.</Warning>

## Удаление профиля доставки

Откройте меню строки в списке профилей и выберите **Удалить**.

<Note>Профиль по умолчанию удалить нельзя: на него опираются товары без отдельного профиля. Сначала назначьте по умолчанию другой профиль.</Note>
