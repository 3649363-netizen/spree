Склад — место хранения товаров и выполнения заказов. Это может быть складское помещение, магазин с подсобной комнатой или внешний центр выполнения заказов. Каждый остаток в магазине относится к складу, и каждый заказ отгружается с одного из них.

Если у магазина один склад, обычно достаточно настроить его один раз. При добавлении новых складов нужно учитывать, что остатки ведутся по каждому отдельно, [перемещения](/user/inventory/stock-transfers) используются для движения товаров между ними, а [профили доставки](/user/settings/delivery-profiles) определяют, какие склады могут отправлять заказы в заданные регионы и по какой цене.

Откройте **Настройки → Склады** в группе **Доставка и отгрузка**.

## Список складов

В каждой строке показаны:

- **Название** — имя склада.
- **Тип** — склад, магазин или центр выполнения заказов.
- **Местоположение** — город и страна из адреса.
- **Самовывоз** — можно ли забрать заказ здесь.
- **Возвраты** — принимаются ли сюда возвращённые товары.
- **Активен** — доступен ли склад для отгрузки.
- **По умолчанию** — склад, к которому относятся новые остатки. Он может быть только один.
- **Продавец** — в marketplace указан продавец, которому принадлежит склад.

Используйте фильтр **Тип**, чтобы показать склады, магазины или центры выполнения заказов.

## Создание склада

Нажмите **Добавить склад**. В панели пять групп параметров.

{/* Скриншот 2: данные склада, переключатели и адресные поля. Сделать снимок русской панели. */}

### Основные сведения

Укажите название и тип места.

- **Название** — имя склада. Если включён самовывоз, покупатель может увидеть его при выборе места получения заказа.
- **Внутреннее название** — необязательная подпись только для команды, если сотрудники называют место иначе, чем покупатели.
- **Тип** — **Склад**, **Магазин** или **Центр выполнения заказов**.

### Поведение

Настройте четыре параметра учёта остатков.

- **Активен** — включено по умолчанию. Неактивный склад нельзя выбрать для выполнения заказа.
- **Склад по умолчанию** — новые остатки относятся к этому складу. Склад по умолчанию может быть только один.
- **Разрешить продажи под заказ по умолчанию** — новые остатки на этом складе будут разрешать продажу при отсутствии товара.
- **Создать остатки для всех вариантов** — автоматически создаёт запись остатка на этом складе для каждого продаваемого варианта товара.

<Warning>Если включить **Создать остатки для всех вариантов**, в учёт сразу попадут все варианты каталога. Для большого ассортимента это создаст много записей. Оставьте параметр выключенным, если на складе есть только часть ассортимента.</Warning>

### Адрес

Укажите:

- **Адрес, строка 1**, **Адрес, строка 2**, **Город**, **Почтовый индекс**, **Страна**, **Штат / провинция**.
- **Телефон**.
- **Компания**.

Полный адрес важен для расчёта тарифов перевозчиками и отображается покупателю при личном получении заказа.

<Note>Вид поля **Штат / провинция** зависит от выбранной страны: для стран с определёнными штатами будет список, для остальных — текстовое поле.</Note>

### Возвраты

Выберите, принимаются ли на склад товары, которые покупатели отправляют обратно.

- **Принимать возвраты здесь** — включено по умолчанию. Отключите, если товары проверяют в другом месте.

<Note>Новый склад автоматически начинает принимать возвраты. Если это не требуется, выключите параметр при создании.</Note>

### Самовывоз

Разрешите покупателям забирать заказы на этом месте.

- **Разрешить самовывоз покупателей** — выключено по умолчанию. При включении склад можно выбрать при оформлении заказа.

Появятся ещё три параметра:

- **Правило наличия** — какие товары можно забрать:
  - **Только товары на этом складе** — покупатель может выбрать самовывоз только для товаров, уже имеющихся здесь.
  - **Разрешить перемещение с других складов** — покупатель может выбрать товары, которые сначала нужно доставить с другого склада.
- **Будет готов через (минуты)** — ожидаемое время подготовки заказа. Укажите срок, за который команда действительно сможет собрать заказ.
- **Инструкции по получению** — куда подойти и что взять с собой. Укажите вход, стойку и документы, если они нужны.

<Warning>При выборе **Разрешить перемещение с других складов** покупатель может оформить самовывоз товара, которого здесь сейчас нет. Включайте этот параметр, только если команда всегда обработает перемещение и доставит остаток; иначе покупатель может прийти за товаром, которого на месте не будет.</Warning>

Заполнив поля, нажмите **Создать склад**.

## Изменение склада

Откройте меню строки и выберите **Изменить**. В панели доступны поля создания, а также два раздела, которые появляются только у существующего склада.

### Остатки на складе

{/* Скриншот 3: варианты, остатки и продажи под заказ. Сделать снимок русской панели. */}

Здесь перечислены все варианты, хранящиеся на складе, их количество **В наличии** и возможность **Продавать под заказ**. Для каждого варианта можно изменить оба значения. Малые остатки помечены как **Заканчивается**.

Найдите товар по названию или SKU через поле поиска. Если записей пока нет, появится сообщение **Остатков на этом складе пока нет**.

<Note>Для ежедневного пересчёта обычно удобнее открыть страницу [«Остатки»](/user/inventory/stock-levels): там видны все склады, а для каждой корректировки можно записать причину.</Note>

### История остатков

Здесь показаны изменения по складу — от новых к старым — и причина каждого изменения. В разделе **Остатки на складе** видно текущее количество, а здесь — как оно изменилось.

{/* Скриншот 4: список движений остатков с причинами. Сделать снимок русской панели. */}

В строке указаны:

- **Дата** — время изменения.
- **Товар** — вариант и его SKU.
- **Место** — склад, по которому зарегистрировано изменение.
- **Изменение** — количество со знаком: поступление или списание.
- **Операция** — **Принят**, **Зарезервирован**, **Отправлен**, **Освобождён** или **Скорректирован**.
- **Причина** — документ, связанный с изменением: заказ поставщику, перемещение, возврат, обмен, отгрузка, заказ или ручная корректировка.

В столбце **Причина** документ указан ссылкой. Например, нажав **Перемещение T1001**, вы откроете документ, по которому перемещали товары. Возвраты и обмены ведут к связанному заказу.

Используйте историю, чтобы выяснить, почему изменилось количество. Если записи не объясняют расхождение, возможно, остаток изменили вне Spree; скорректируйте его и укажите причину.

<Note>Если на складе ещё не было остатков, появится сообщение **Остатки ещё не изменялись**.</Note>

Закончив, нажмите **Сохранить**, затем **Закрыть**.

## Склад по умолчанию

Новые остатки относятся к складу по умолчанию. Чтобы изменить его, откройте нужный склад, включите **Склад по умолчанию** и сохраните изменения.

<Note>Склад по умолчанию может быть только один. Если включить этот параметр у другого склада, он выключится у предыдущего.</Note>

## Удаление склада

Откройте меню строки и выберите **Удалить**.

<Warning>При удалении склада удаляются связанные с ним записи остатков. Если товары нужно переместить в другое место, сначала оформите [перемещение](/user/inventory/stock-transfers), чтобы сохранить историю движения.</Warning>
